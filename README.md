I operate at the nexus of **design engineering, AI-augmented development, and quality assurance**. I translate visionary design into flawless, production-ready web applications — combining modern frontend architecture, AI/LLM-powered tooling and workflows, and rigorous testing discipline. ### UI Forms
**React • TypeScript • Accessible Components • Modern CSS**

A component-driven UI project focused on building accessible, reusable form patterns — engineered for consistent validation states, clear error handling, and inclusive interaction design across devices.

#### Key Outcomes
*   **Architected** reusable, WCAG-aligned form components (inputs, validation states, multi-step flows) to speed up feature delivery.
*   **Implemented** accessibility-first interaction patterns, including keyboard navigation and ARIA-based error announcements.
*   **Established** a scoped, token-driven CSS architecture for consistent theming and long-term maintainability.

🔗 Live Demo: https://ui-forms.netlify.app

### Marci Metzger Homes
**Next.js • TypeScript • GSAP • Modern CSS**

A premium, conversion-focused real-estate landing experience emphasizing high-end interaction quality and rapid rendering.

#### Key Outcomes
*   **Architected** complex, high-performance entrance effects and scroll-driven animations utilizing GSAP ScrollTrigger.
*   **Leveraged** modern CSS capabilities, including native nesting, cascade layers (`@layer`), and relative color syntax (`oklch(from...)`) for dynamic palette generation.
*   **Optimized** asset delivery pipeline using AVIF/WebP image formats and Turbopack to consistently hit **90+ PageSpeed scores**.

🔗 Live Demo: https://metzger-homes.netlify.app

## Engineering Philosophy

### Systems Over Screens
A single page can be redesigned. A robust system scales across products.

### Performance Is Part of Design
Fast experiences improve usability, engagement, and business outcomes.

### Accessibility Is Non-Negotiable
Inclusive interfaces should be built into the foundation, not added later.

### Maintainability Creates Longevity
Clean architecture enables teams to move faster over time.

### Quality Is Designed, Not Just Tested
Proactive quality integration from conception to deployment ensures superior user experiences.

### AI as a Force Multiplier
LLM-powered tooling accelerates prototyping and review, but engineering judgment stays firmly in the loop.
